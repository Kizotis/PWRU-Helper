# Story E1.S1: Inject an `HttpMessageHandler` into every HTTP provider

Status: **review**

_Epic E1 (A) — Diagnosable translation pipeline · increment 0 · Release A.0 · ⛔ no production code until the
owner's explicit go (ground rule 2, `docs/investigations/README.md`)._

## Story

As the maintainer,
I want every HTTP provider to accept a test handler,
So that the retry policy, the breaker and every response parser can be proven headless instead of being unreachable.

## Acceptance Criteria

_Copied verbatim from `docs/investigations/03-stories/epics.md` § Story E1.S1. Do not weaken._

1. **Given** `Services/TranslationService.cs:32` holds a `private static readonly HttpClient` that no test can reach
   **When** the class gains `internal TranslationService(HttpMessageHandler? handler = null)`
   **Then** passing `null` uses the existing shared static client and passing a handler creates a private
   `new HttpClient(handler)`
   **And** the same overload exists on `Services/DeepLTranslator.cs:16`
   **And** the production shared clients are built on a `SocketsHttpHandler` with `PooledConnectionLifetime = 2 min`
   (`TranslationService.cs:37-44`, `DeepLTranslator.cs:80-110`).
2. **Given** the suite has no HTTP test double at all (`analyse…` §6.4 gap 3)
   **When** a `FakeHandler : HttpMessageHandler` is added to `tests/PWRUHelper.Tests`
   **Then** it can return an arbitrary status, content-type and body, can throw a transport exception, can delay, and
   counts the attempts it received.
3. **Given** `tests/PWRUHelper.Tests/TranslationBackendTests.cs:78` constructs the existing exception type
   **When** the seam lands
   **Then** that call site still compiles and the whole suite is green.

## Dev Notes

### Invariants this story must keep

- **I1** — `ITranslator` keeps its exact shape (`TranslationService.cs:18-23`). A ctor overload is not an interface
  change. Do not touch the interface.
- **I2** — `Services/` stays UI-free and headless-testable.
- **I3** — do not add or move any `catch (OperationCanceledException)` here. The DeepL filter at
  `DeepLTranslator.cs:80` (`when (ct.IsCancellationRequested)`) is load-bearing and stays exactly as it is; E1.S3
  is where classification moves.
- **I16** — the LIVE loop is not touched at all in this epic.

### Rulings and decisions that apply

- Every ⛔ story is gated on the **owner's Phase-4 go**. This story writes no code before it.
- **Sprint-plan note 4 (read this):** the `SocketsHttpHandler` / `PooledConnectionLifetime = 2 min` clause is the
  **only** behaviour-adjacent change in a "zero behaviour change" increment. Today there is no `SocketsHttpHandler`
  anywhere in the codebase. It is justified — Phase 0 fact F6 / Q2.6, a stale pooled connection on a
  process-lifetime static client is a candidate for "a block that never clears" — and it is kept, but **call it out
  explicitly in the PR description** so it is not mistaken for a pure refactor.
- **Sprint-plan note 5:** `epics.md` cites `DeepLTranslator.cs:80-110` for the client construction. That range is
  the send / OCE-filter / status-mapping region. The DeepL client is constructed at **`DeepLTranslator.cs:16`** —
  that is the line this story edits.

### Repo traps

- `PWRUHelper.csproj:28` grants `InternalsVisibleTo PWRUHelper.Tests` and `:18` excludes `tests\**` from the app's
  globbing. **Both must stay intact** — that is what makes an `internal` ctor testable and keeps the test sources
  out of the app build.
- **No `.sln` at the repo root.** Adding one breaks `dotnet run` and both `Build *.bat` scripts.
- `dotnet test tests/PWRUHelper.Tests` must stay **headless-safe** — CI runs it on `windows-latest` on every PR
  (`.github/workflows/ci.yml:24`). No display, no network, no `%AppData%` write.
- No new NuGet package (NFR6 / CI-10). xUnit 2.9.2, Test SDK 17.11.1, runner 2.8.2 only.

### Current state of the files being modified

- `Services/TranslationService.cs` — `TranslationException` (`:10-13`, message-only ctor), the `ITranslator`
  interface (`:18-23`), the static client (`:32`), `CreateClient()` (`:37-44`, plain `HttpClient` + UA), the
  batch/per-line path with its `rateLimited` latch (`:99-105`), the retry loop (`:119-178`) with its single
  `Http.GetAsync` at `:131`, and `ChunkText`/`HardSplit` (`:181-218`). This story touches **only** the client
  construction and the call site; everything else stays byte-identical.
- `Services/DeepLTranslator.cs` — static client (`:16`), public ctor (`:21-27`), the OCE filter (`:80`) and the
  status mapping (`:96-106`). This story touches **only** `:16`, the ctor and the send call at `:78`.
