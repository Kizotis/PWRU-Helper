## Story

As a player,
I want every status line to tell me the reason and the way back,
So that a stopped feature never leaves me guessing what to press.

## The four sections, verbatim

**§3.2 — LIVE statuses** (seven):

| Situation | String |
|---|---|
| running (unchanged) | `🔴 Live — watching (check #{n})…` |
| one failed read, still trying | `🔴 Live — one read did not translate, retrying…` |
| the preferred engine is paused, a backup serves | `🔴 Live — {P} paused ({t}), using {P2}.` |
| everything paused | `○ Live — paused, next try in {t}. It resumes on its own; nothing is lost.` |
| recovered | `🔴 Live — back on. Catching up on {n} message(s).` |
| auto-stopped, honestly | `Live stopped — {n} reads in a row failed. Press ▶ to try again.` |
| auto-stopped because everything is paused past the cap | `Live stopped — every engine is paused. Try again in {t}, or add the offline engine in About.` |

**§3.3 — Read-once** (five): `Done — {n} line(s) translated.` ·
`Read {n} line(s) — {k} translated, {m} could not be. {reason}` ·
`Read {n} line(s) — none could be translated. {reason}` ·
`Read {n} line(s) — all engines are paused. They will fill in when one is back.` ·
`Could not read the screen: {reason}`

**§3.4 — Overlay quick reply** (four, **under ~60 characters** — the overlay is 360 px wide):
`⚠ {reason} — your text is kept, press Enter to retry.` · `⚠ Engines paused ({t}) — your text is kept.` ·
`⚠ No internet — your text is kept, press Enter to retry.` · `⚠ Your {P} key was refused — see About.`

**§3.5 — Fallback notice** (three, once per switch, status line only):
`Translated by Edge — Google is paused.` · `Translated by the offline engine — no internet needed.` ·
`Back on Google.`

### Completion Notes List

**The one behavioural change: amendment A8, the "Cancel read" affordance (T8, ruling E5-g).**

`SetReadOnceEnabled(bool)` is gone — name and behaviour — and `SetReadOnceCancelMode(bool reading)` replaces
it on both surfaces. It **never writes `IsEnabled`**: a disabled WPF button raises no `Click`, which is why
two of E5.S4's three cancel routes were unreachable and why "only Ctrl+Alt+R can stop a read" was literally
true. What it swaps instead:

| Surface | Idle | While `_readingOnce` |
|---|---|---|
| `SelectAreaButton` | `Select area & read once` + its tooltip | `Cancel read` + `Stop this read — Ctrl+Alt+R does the same.` |
| overlay `ReadOnceButton` | `👁 Read once` + its tooltip | `■`, `ToolTip` and `AutomationProperties.Name` = `Cancel read` |

A8's **two mandatory conditions** are both met and both pinned: the `if (_readingOnce) { CancelReadOnce();
return; }` guard is now the **first line of `SelectAreaAndReadOnceAsync`** (ahead of `StopLive()` and
`SelectRegionAsync()`, or a cancel press would start a region drag over the game — the guard is written three
times rather than moved, because the hotkey path and the engine guard inside `ReadRegionOnceAsync` are
different jobs), and nothing is ever greyed. The overlay's button reaches the same method, so **■ cancels a
read from compact mode** — one entry point, zero new controls. The existing CTS path from E5.S4 does the
cancelling, so I3, `_readOnceStopped` and the `Read cancelled.` status are untouched and still green.

The two buttons now have **no `Content` and no `ToolTip` in their XAML at all**: a control whose label changes
cannot keep it in an attribute, or the restore is a second spelling of it (UX-DR19). The copy is in
`UserMessages` and written at construction, exactly as `SetKeyTestLabels()` does for the key boxes (E6.S5) —
plus `EnterCompactMode`, which pushes the real state because Ctrl+Alt+R can be reading when the player goes
compact.

**Decision 1 — §3.2's S3 row (`🔴 Live — {P} paused ({t}), using {P2}.`) is NOT rendered; the chip and the
one-time notice carry S3.** Three reasons, each an invariant this epic already holds: (1) **one clock per
window** — in S3 nothing is fully paused, so the chip owns the clock and steps `Google paused 0:58` at 1 Hz;
a second `({t})` on the status line is a second clock, and a coarse one (E7-a) is worse, because it is the

it either** — a deck sentence nothing renders is UX-DR19's failure the other way round, which is the argument
E7.S4 made when it declined §3.2's "⚠ one read is retrying" overlay column. Pinned behaviourally by
