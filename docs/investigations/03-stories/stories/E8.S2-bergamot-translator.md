# Story E8.S2: `BergamotTranslator` — an `ITranslator` over a synchronous native engine ⛔ Phase 4 (prototype branch)

Status: **blocked-dep · ⛔ Phase 4 · prototype branch only — hard gate on E8.S1's go/no-go numbers**

_Epic E8 (H) — Offline fallback prototype · increment 7 · **Release C** · prototype branch, merges only on a go._

> **No code before the numbers.** E8.S1 is a hard gate, exactly as E3.S2's capture is for E3.S5: if the resident
> delta does not come back at or under 150 MiB for one model, or if the memory is not returned on unload, this
> class is never written. That is not caution — `plan-migration.md` increment 7 says any single go-criterion
> failing is a no-go and the branch closes.
>
> **This story is the provider and only the provider.** Three neighbouring concerns that `epics.md` § E8.S2
> bundled into it are their own stories, because each touches files this one does not and each is separately
> testable: the **keep-loaded-while-LIVE lifetime** is **E8.S4**, the **model store and the one-click install**
> are **E8.S3**, and the **chain placement, the chip and the cache drop rule** are **E8.S5**. What is left here
> is a class in `Services/` that turns text into text, and it is the only piece the other three cannot stub.

## Story

As a player with no internet,
I want translations to keep working,
So that an outage does not end my evening.

## Acceptance Criteria

_AC 1, AC 2, AC 4 and AC 5 are copied **verbatim** from `epics.md` § Story E8.S2. Do not weaken. Its remaining
two ACs are not lost — the A-1(b) keep-loaded AC is **E8.S4** AC 1, verbatim, and the `github.com`-mirror AC is
**E8.S3** AC 6, verbatim._

1. **Given** §7.6 and amendment A-1
   **When** the provider is written
   **Then** it sits **last** in both chains, behind `OfflineFallbackEnabled` (default false — false means the
   tier is **not even constructed**), references `BergamotTranslatorSharp` (MPL-2.0, NuGet 0.5.1) **on this
   branch only**, and runs the synchronous `BlockingService.Translate` inside `Task.Run` — never on the UI
   thread.
   _The "sits last in both chains" half is **implemented in E8.S5**, which owns `TranslationChains`. This story
   must make it **possible** and must not make it impossible: the class takes its dependencies as constructor
   arguments and reaches for no static the builders do not already own._

2. **Given** I6
   **When** a line is translated
   **Then** it has already been through `SlangGlossary.Expand`; the displayed original and the 🔑 line stay raw.
   A local engine placed *instead of* the glossary is unusable (measured: `данж` → "dangling", `хил` → "heel",
   `спс` → "ps").

3. **Given** I10
   **When** the app starts
   **Then** nothing is loaded — the first load happens on the first fallback use, or on the first LIVE tick
   after the user enabled it, never at startup.

4. **Given** §7.6 constraint 7
   **When** the model is missing or initialisation fails
   **Then** the two failure modes return a `(`-prefixed placeholder, so nothing is cached (I4); the engine
   cannot time out, so I3 does not apply to this leg.
   _`[RULING E8-c, in this story]` In the E1/E3 world that shipped after §7.6 was written, a provider does not
   **return** a placeholder — it **throws** a typed `TranslationException`, and the `(`-prefixed sentence the
   player reads is rendered upstream from `UserMessages`. The invariant this AC actually protects is **I4:
   nothing failed is ever cached**, and a throw satisfies it more strongly than a return does, because
   `CachingTranslator` never sees a value at all. See "The two failure modes, in the current error model" below
   for the exact shape and for why **neither of them may set `NotSent`**._

5. **Given** the thread rule
   **When** `TranslateAsync` / `TranslateLinesAsync` are called
   **Then** the synchronous native call runs on `Task.Run`, never on the UI thread, and the class is safe to
   call from two threads at once — the read chain and the write chain share one process and the LIVE loop is
   sequential but the Translator tab is not.

6. `[DERIVED — I1, architecture-cible.md §16]` **Given** I1
   **When** the class is written
   **Then** it implements `ITranslator` unchanged — two methods, `ct` last, `Task<string>` /
   `Task<List<string>>` — and adds no member to the interface. New behaviour arrives as an implementation, never
   as an interface change.

**Definition of done for the story.** With a model present on disk and the network disabled, a call through this
class returns a translation; with the model absent, it throws the typed failure and nothing reaches the cache.

## Tasks / Subtasks

- [ ] **T1 — `Services/BergamotTranslator.cs` (AC 1, AC 6).** New file, namespace `PWRUHelper.Services`,
      `internal sealed class BergamotTranslator : ITranslator`. Glossary row: `architecture-cible.md` §16.
  - [ ] Constructor takes **(a)** the model directory as a `string` — **not** a path this class derives, because
        E8.S3 owns the store and E8.S1's harness needs to point it at `%TEMP%`; **(b)** an optional
        `ProviderGate?` defaulting to `null` and resolved lazily as `_gate ?? ProviderGates.For(ProviderIds.Bergamot)`,
        exactly as `HttpProviderCore.cs:91-97` does it; **(c)** an optional engine factory, so every test in
        E8.S3/S4/S5 can run against a fake without a 22 MB DLL.
  - [ ] `ProviderIds.Bergamot` already exists (`Services/ProviderGates.cs:22`, and it is in `All` at `:31`).
        Do not add a literal `"bergamot"` anywhere.
  - [ ] The display name already exists too: `ProviderNames.Display` → **"Offline engine"**, `Short` →
        **"Offline"** (`Services/ProviderNames.cs:38, :46-49`). Nothing in this story invents a name.

- [ ] **T2 — The engine seam (AC 1, AC 5, and it is what makes every later story testable).** Define a tiny
      internal interface over the **three** C exports the native surface has (`benchmark…` §6.2):
      `translator_initialize(configPaths, n)` · `translator_translate(handle, text, html)` ·
      `translator_free(handle)`.
  - [ ] One production implementation delegating to `BergamotTranslatorSharp`'s `BlockingService`; one test
        double implementing the same three calls. **The fake is the fixture for the whole epic** — test-plan
        §3.13 is a field campaign, so every automated case in E8.S3/S4/S5 runs on the fake.
  - [ ] Keep the seam at **three methods**. It is a P/Invoke surface, not an abstraction layer; the Rule of
        Three has not been met for anything wider.

- [ ] **T3 — Lazy load, once, thread-safe (AC 3, AC 5).**
  - [ ] `Volatile.Read` + `lock` double-check, or a `Lazy<T>` with
        `LazyThreadSafetyMode.ExecutionAndPublication`. Two concurrent first calls must produce **one** engine —
        two would be 254 MiB.
  - [ ] **Nothing in the constructor touches disk.** `ProviderGates.For` "constructs only — it reads no file"
        (`ChainTranslator.cs:187-189`), which is why calling it from a constructor keeps I10. The same rule binds
        here: the constructor may compute a path and must not stat it, read it or load anything from it.
  - [ ] The load is triggered by the first **translate call**, not by construction, not by a health check, not
        by the About tab painting. The `TranslationCacheStore.Count` comment
        (`TranslationCacheStore.cs:193-196`) is the precedent, and its wording is the rule: *"a count is not a
        question about a translation"*.
  - [ ] **Do not call `ProviderGate.TryEnter`.** The gate's admission is a token bucket and a rate ceiling built
        for a remote endpoint; a local engine has no rate to limit, and taking a token would let the offline
        tier consume the reserve §5.4 keeps for interactive traffic. This class uses the gate for **one** thing:
        recording a failure so the chain skips it next time (T5).

- [ ] **T4 — `Task.Run` around every native call (AC 1, AC 5).**
  - [ ] `BlockingService.Translate` is synchronous (§7.6 constraint 3, `benchmark…` §10's "what still counts
        against it" #2). Wrap **the whole native interaction** — initialize included, because 103–500 ms of init
        on the UI thread is a visible freeze.
  - [ ] `ct.ThrowIfCancellationRequested()` before and after; the native call itself is not cancellable, so the
        honest contract is "we do not start one you cancelled, and we discard the result of one you cancelled".
  - [ ] **I3 does not apply to this leg and the code must say why**: the engine cannot time out, so there is no
        `OperationCanceledException` here whose token is *not* cancelled. A bare `catch (OperationCanceledException)`
        is still forbidden — write the `when (ct.IsCancellationRequested)` filter if a catch is needed at all,
        because the next person to read this file will be looking for it.
  - [ ] **Batching:** the wrapper's `Translate(IEnumerable<string>)` wraps lines in `<p>` and calls with
        `html: true` — one native call per OCR frame (§6.2). Use it for `TranslateLinesAsync`.
  - [ ] **I5 — a batch count mismatch is never padded.** If the HTML split returns a different count than the
        input, throw `BadResponse`. §6.3's join/split per-line fallback is for the *cloud* join providers; a
        local engine returning the wrong count is a bug, not a shape to route around.

- [ ] **T5 — The two failure modes (AC 4), and the ruling that shapes them.** See the Dev Notes table.
  - [ ] **Model missing** → the tier should **not exist**: E8.S5 builds it only "if `OfflineFallbackEnabled` and
        the model is present". A missing model reaching this class is therefore a race (the user pressed Remove
        mid-session), and it throws `TranslationException(TranslationErrorKind.Unavailable, …, providerId:
        ProviderIds.Bergamot)`.
  - [ ] **Init failed** → the same `Unavailable`, **plus** `gate.ReportFailure(TranslationErrorKind.Unavailable)`
        so the gate opens a soft window and `ChainTranslator` skips the tier on the next call **without an
        exception at all** — `RunAsync`'s `if (BlockedUntil(tier, out var snapshot) is { } until) { … continue; }`
        (`ChainTranslator.cs:243-247`) is the skip path, and it needs no flag.
  - [ ] **`NotSent` must NOT be set.** `ChainTranslatorTests.NotSent_is_written_in_exactly_one_place`
        (`:519-527`) scans production sources for `NotSent\s*=(?!=)` and asserts exact equality with
        `new[] { "HttpProviderCore.cs" }`. A second writer fails that test, and rightly: ruling E3-b gives the
        flag one owner, and its meaning — "the gate refused before anything left the machine" — is a statement
        about a **request**, which a local engine never makes.
  - [ ] Cache the "engine is broken" state so a failed init is not retried on every line of a 40-row frame. The
        gate's window is that cache; a private `_initFailed` bool **in addition** would be a second, disagreeing
        one.

- [ ] **T6 — Unload, and prove the memory comes back (AC 3's other half; E8.S4 owns *when*).**
  - [ ] `IDisposable` / an internal `Unload()` calling `translator_free` and dropping the handle, idempotent and
        safe against a translate in flight (take the same lock).
  - [ ] **This story provides the capability. E8.S4 provides the policy** (kept loaded while LIVE runs, unloaded
        after LIVE stops + an idle timeout). Do not put a timer in this class — a `Services/` type that owns a
        clock and a timer is what E8.S4 makes unit-testable with an injected one.
  - [ ] E8.S1's go-criterion 4 is what says this is possible at all: if the working set does not return to its
        pre-load value after `translator_free`, say so and stop.

- [ ] **T7 — I6, and it is a **pin**, not an implementation (AC 2).** This class must **never** call
      `SlangGlossary.Expand`. The chain receives text that has already been expanded, upstream, at
      `MainWindow.Live.cs:948` (`bodies.Select(b => _slang.Expand(b))`) and `MainWindow.Translate.cs:99`
      (`from == "ru" ? _slang.Expand(text) : text`).
  - [ ] Write the pin as a **test that scans this file's source** for `Expand` and asserts it is absent, in the
        shape `ChainTranslatorTests` already uses for `NotSent`. A comment can be deleted; a scan cannot.
  - [ ] The reason is measured, not stylistic (`benchmark…` §10): expanding **inside** the provider would expand
        text the cloud tiers already expanded, and expanding it twice is exactly what
        `Services/PendingRetryQueue.cs:7` warns about.

- [ ] **T8 — MPL-2.0 in the licence tree (§7.6 constraint 8).** The DLL, the models and the wrapper are all
      MPL-2.0 and the app is MIT. Add the notice to the About tab.
  - [ ] File-level copyleft is compatible with shipping beside an MIT app; it is still a **second licence**, and
        SignPath Foundation requires the app itself to stay OSI-licensed (MIT) — which it does.
  - [ ] The exact placement of the About text is **E8.S3's** block (§4.2's "Offline engine (optional)"); this
        story supplies the sentence and the obligation, so that a merge with E8.S3 dropped cannot ship the DLL
        with no notice.

## Dev Notes

### The two failure modes, in the current error model — ruling **E8-c**

§7.6 constraint 7 was written before E1 landed the typed errors and before E3 landed the chain. Read literally
("return a `(`-prefixed placeholder") it would have this class do something no provider in the app does any more.
What it *protects* is I4, and here is the mapping, which is what the dev implements:

| §7.6's words | What it means now | Why |
|---|---|---|
| "returns a `(`-prefixed placeholder" | **throws** `TranslationException(Unavailable, …, providerId: bergamot)` | Every provider since E1.S2 signals by Kind. `UserMessages` renders the sentence the player reads; `ProviderNames.Display("bergamot")` puts **"Offline engine"** in it (`ProviderNames.cs:38`). |
| "so nothing is cached (I4)" | **stronger than before**: `CachingTranslator` is never handed a value | `CachingTranslator.cs:64` stores only on `IsCacheable`; a throw means there is nothing to test. |
| "it cannot time out, so I3 does not apply" | unchanged, and it is written in the code | There is no `HttpClient` here, so no `TaskCanceledException`-with-live-token. The comment exists so a future reader does not "helpfully" add a broad catch. |
| — | **`NotSent` is not set** | `ChainTranslatorTests.NotSent_is_written_in_exactly_one_place` asserts exactly one writer (`HttpProviderCore.cs`). Ruling E3-b's flag means "no request left the machine", which is a statement about a request. |
| — | the **gate** carries the skip | `ChainTranslator.RunAsync` skips a gated tier before calling it (`:243-247`) — no exception, no flag, and the skip lands in `Outcome.Skipped` where E7's chip already reads it. |

**Is a `ProviderGate` useful for a local engine at all?** Yes, for exactly one of its two jobs. The **rate
ceiling** is useless — there is nothing to be polite to. The **breaker** is valuable: an engine that failed to
initialise will fail again in 200 ms, and a 40-row LIVE frame would pay that 40 times. One `ReportFailure` opens
a soft window, `ChainTranslator` skips the tier for its duration, and `ProviderGate`'s half-open probe re-arms it
for free. The gate also gives E7's chip and tooltip a state to render without a second mechanism.

### Repo traps

- **`ProviderGates.For` is safe from a constructor; `TryEnter` is not.** The first constructs only; the second
  is what loads `provider-state.json` on its first call (`ChainTranslator.cs:187-189`, and
  `TranslationChains.OnKeySaved`'s remark at `:133-143` spells out the ordering trap that follows).
- **`ChainTranslator.Of` registers a gate per tier id and refuses a duplicate id** (`:191-213`). Adding
  `bergamot` twice — say, once in a builder and once in a test helper — throws at composition time, which is the
  design working.
- **The suite has two non-parallel collections** (`WPF`, `Gates` — CI-5). Anything this story adds that touches
  `ProviderGates` belongs in the `Gates` collection with its `ResetForTests()` fixture, or it will leak state
  into a neighbouring case (R4).
- **`Data/slang.json` is both embedded and copied** (`PWRUHelper.csproj:45-48`). Irrelevant to this class by
  construction — which is the point of T7's scan.
- **Do not "optimise" by keeping the engine loaded.** The whole argument for shipping this at all is that it
  costs **0 MB at rest**. A convenience `_engine` that never unloads turns a 127 MiB opt-in into a permanent tax
  on a product whose stated virtue is not lagging the game.

## Size, dependencies, risk

**Size:** **L** — the largest story of the epic and one of two `L`s in the whole 62-story cut (`epics.md`
"Story sizing"). Native interop, a lifetime, a thread contract and a failure model, in one class ·
**Depends on:** **E8.S1** (hard gate — its five numbers, and specifically go-criterion 4: the memory must come
back); E3.S7 for the chain that will hold it ·
**Blocks:** E8.S3, E8.S4, E8.S5 — all three stub against this class's engine seam ·
**Risk:** **high on footprint** — one model is ~85 % of the app's current working set — accepted by the owner
under A-1(c), and bounded by E8.S1's measurement. **Medium on interop**: `UnmanagedType.HString` marshalling was
removed in .NET 5+ and this project has been bitten by native-interop assumptions before (`WgcCapture`); the
three C exports here take plain `const char*`, which is the easy case, but verify rather than assume ·
**DoD:** the tier works end-to-end on the branch with the network disabled.

## How to verify manually

1. On the branch, with a model in place and **the network disabled**, translate one Russian line through the
   Translator tab: it comes back, and the chip says `● Offline` (the chip is E8.S5 — before it lands, read
   `ChainTranslator.LastOutcome.ProviderId`).
2. Launch and do nothing: Process Monitor shows **zero** reads under the model directory (AC 3, I10).
3. Delete the model, restart, translate: the typed failure surfaces as "Offline engine …" copy, and
   `translation-cache.json` gains **no** entry (AC 4, I4).
4. Watch the working set across load → first translate → unload; it comes back down.
5. Translate a slang line (`го пати на босса, нужен хил`): the output is the **expanded** one, and the displayed
   original and the 🔑 line are still raw (AC 2, I6).
