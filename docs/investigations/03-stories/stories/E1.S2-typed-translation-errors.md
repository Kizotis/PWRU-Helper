# Story E1.S2: Introduce `TranslationErrorKind` and a typed `TranslationException`

Status: **ready-for-dev (Phase 4 — owner's go required)**

_Epic E1 (A) — Diagnosable translation pipeline · increment 0 · Release A.0 · ⛔ no production code until the
owner's explicit go._

## Story

As a support-reading maintainer,
I want every translation failure to carry a machine-readable kind,
So that the message a player sees and the decision the code takes stop being derived from a string.

## Acceptance Criteria

_Copied verbatim from `epics.md` § Story E1.S2. Do not weaken._

1. **Given** `Services/TranslationErrors.cs` does not exist
   **When** it is created
   **Then** it declares the 11-value `TranslationErrorKind` of `architecture-cible.md` §4.1 verbatim
   (`RateLimited, Blocked, Unavailable, Timeout, Network, BadResponse, QuotaExhausted, AuthFailed, Cancelled,
   AllProvidersPaused, Unknown`)
   **And** `TranslationException` carries a required `Kind` plus optional `RetryAt` and `ProviderId`
   **And** **there is no message-only constructor**.
2. **Given** the twelve existing throw sites (`TranslationService.cs:143,145,148,157,175`;
   `DeepLTranslator.cs:53,60,87,91,99,127`)
   **When** the message-only constructor is removed
   **Then** the compiler forces each of them to state a `Kind`, and each one states the `Kind` the §4.2 table
   assigns.
3. **Given** the `Cancelled` contract of §4.1
   **When** a provider recognises a genuine cancellation
   **Then** it **rethrows the original `OperationCanceledException`** and never wraps it; a `TranslationException`
   with `Kind.Cancelled` is never constructed anywhere in the codebase.

## Dev Notes

### Invariants this story must keep

- **I3 — the OCE trap, and this story is where it becomes a contract.** An `HttpClient` timeout throws
  `TaskCanceledException` (an `OperationCanceledException` subclass) with the token **NOT** cancelled. Every OCE
  catch filters `when (ct.IsCancellationRequested)`. The existing filters at `DeepLTranslator.cs:80` and
  `FallbackTranslator.cs:26,38` — and the bare rethrow at `TranslationService.cs:104`
  (`catch (OperationCanceledException) { throw; }` in the per-line loop, which is correct because it rethrows
  rather than converting) — all stay exactly as they are. Reintroducing a broad catch here
  silently disables the fallback and leaves a zombie LIVE indicator — the project's most expensive past bug.
- **I1** — no change to `ITranslator`. **I2** — `Services/` stays UI-free. **I5** — `DeepLTranslator.cs:49-53`
  still throws instead of padding; only the `Kind` is added. **I16** — the LIVE loop is untouched.

### Rulings and decisions that apply

- `Kind.Cancelled` exists **only** so `ProviderErrorMapper` can be a total function (E1.S3). Nothing constructs it.
  TP-MAP-17 is what keeps that true.
- **`AllProvidersPaused` and `Unknown` are declared here but wired to nothing yet.** `AllProvidersPaused` becomes
  reachable in E3.S3 (`ChainTranslator`); `Unknown` becomes the mapper's last resort in E1.S3. Declaring the whole
  enum now is deliberate — the file is the vocabulary, not the behaviour.
- This story changes **no user-visible string**. Every message stays byte-identical; only a `Kind` is added in
  front of it. E1.S6 then maps `Friendly()` onto `Kind` with the same wording, and **E7.S1** brings Sally's real
  copy (via `Services/UserMessages.cs`, the GAP-4 ruling) — not before.

### Repo traps

- `TranslationException` is `public` today and is referenced from `MainWindow.xaml.cs:404-410`,
  `MainWindow.Translate.cs`, `MainWindow.Live.cs`, `MainWindow.Ocr.cs` and the test project. Keep it `public` and
  in namespace `PWRUHelper.Services` so no using-directive churn is needed.
- `InternalsVisibleTo PWRUHelper.Tests` (`PWRUHelper.csproj:28`) and the `tests\**` `DefaultItemExcludes` (`:18`)
  stay intact. **No `.sln`.**
- `dotnet test tests/PWRUHelper.Tests` stays green and headless.
