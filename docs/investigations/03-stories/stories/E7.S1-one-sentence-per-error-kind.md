# Story E7.S1: One sentence per error kind, with a countdown

Status: **review**

_Epic E7 (G) — Degraded-mode UX · increment 6 · **Release B.2** · the owner's Phase-4 go was given 2026-09-06
(`README.md` § Phase 4)._

> **This is the story E1.S6 was written to be reversed by.** `Services/UserMessages.cs` already exists — GAP-4's
> single table, nine sentences, UI-free, house-rule-tested. What it holds is Sally's deck with **four deliberate
> deviations**, every one of them recorded, ruled on by Winston and marked *"E7.S1 restores the full form"*:
>
> | | Deviation | Why it was taken | What restores it |
> |---|---|---|---|
> | **D1** | **no `{P}`** — no sentence names an engine | naming the answering provider needed `ChainTranslator.LastOutcome`, which did not exist | it does now (E3.S3, `ChainTranslator.cs:101-104`) + **E7.S3**'s provider-name table |
> | **D2** | **no "— trying another engine"** | `Friendly` was only ever reached *after* the whole attempt had already failed; promising a retry that is not happening breaks principle 4 | the sentence now also renders on a **status line above a live chain**, where the promise is true |
> | **D3** | **no `{t}`** in `RateLimited`, `Blocked`, `AllProvidersPaused` | no gate to count down from, and no formatter | **E2** shipped the gate; **E7.S2** ships the formatter |
> | **D4** | **no terminal full stop** | all six call sites *join* the sentence; with the stop the app shipped `…shortly.).` and `. — your text is kept` | §3.1's terminated form for the **standalone** surfaces + `LowerAtJoin` for the joins |

> *"— using the free engines instead"*; `RateLimited`'s *"try again in a moment"* sits next to the one phrasing

> answered.** If Sally has not, ship §3.1 verbatim — that is the deck, and "verbatim" is a defensible default
> where a reviewer's rewrite is not.

## Story

As a player,
I want one plain sentence that says what happened, when it ends and whether I must do something,
So that I stop reading developer-speak about HTTP responses.

## Acceptance Criteria

_Copied verbatim from `epics.md` § Story E7.S1. Do not weaken._

1. **Given** the `Kind` switch shape landed in E1.S6 (`MainWindow.xaml.cs:404-410`)
   **When** the real copy replaces the placeholders
   **Then** each `Kind` returns exactly the sentence of `ux-mode-degrade.md` §3.1 — `RateLimited`
   (`{P} asked us to slow down — paused for {t}.`), `Blocked`, `Unavailable`, `Timeout`, `Network`, `BadResponse`,
   `QuotaExhausted`, `AuthFailed`, `AllProvidersPaused`
   (`All engines are paused — next try in {t}. Nothing you need to do.`), and **`Cancelled` renders nothing at
   all**.
2. **Given** the copy rules of §3
   **When** any of those strings is reviewed
   **Then** it contains no HTTP status code, no provider internal (`gtx`, `dict-chrome-ex`, `429`), no exclamation
   mark, and it is ≤ 80 characters wherever the overlay can show it.
3. **Given** UX-DR19
   **When** the codebase is searched
   **Then** each user-facing string exists **exactly once** — no ad-hoc re-phrasing at a call site; that is what
   the ten strings E1–E10 cost this project.
4. **Given** a successful fallback
   **When** a lower tier answered
   **Then** **no error text appears anywhere** — the user got their translation; only the chip changes plus the

5. **Given** I2
   **When** `{t}` is rendered
   **Then** `MainWindow` formats the countdown from `RetryAt`; `Services/` never formats a string for display.

## §3.1, verbatim — the target

| Kind | Sentence | Notes |
|---|---|---|
| `RateLimited` | `{P} asked us to slow down — paused for {t}.` | never "wait a minute": we now know the real number |
| `Blocked` | `{P} is refusing requests from your connection — paused for {t}.` | the honest wording for a 403 / captcha page |
| `Unavailable` | `{P} is down right now — trying another engine.` | 5xx |
| `Timeout` | `{P} took too long to answer — trying another engine.` | |
| `Network` | `No internet connection — nothing can be translated until it is back.` | the only kind with no `{P}` |
| `BadResponse` | `{P} sent something we could not read — trying another engine.` | |
| `QuotaExhausted` | `Your {P} free quota is used up — using the free engines instead.` | keys only |
| `AuthFailed` | `Your {P} key was refused — check it in About, or clear it.` | keys only |
| `Cancelled` | *(nothing)* | must never reach a surface |
| `AllProvidersPaused` | `All engines are paused — next try in {t}. Nothing you need to do.` | the single most important line in this document |

`{P}` is the stable user-facing provider name of **OQ-2**: `Google`, `Edge`, `Google (old)`, `DeepL`, `Azure`,
`Offline engine`.

**D1 — `{P}` comes from the EXCEPTION, not from `LastOutcome`.** §3.0/A3 says "`{P}` comes from
`LastOutcome.ProviderId` only", and that is right for the chip (who *answered*). It cannot be right
for a failure sentence: `ChainTranslator` publishes `Publish(null, skipped, kind)` on both failing
exits, so `LastOutcome.ProviderId` is **null on exactly the exit that produces a sentence**. The
carrier of "who failed" is `TranslationException.ProviderId`, which `HttpProviderCore` stamps on
every failure it raises — so `Friendly` reads that, and `ProviderNames.Display` turns it into a name
or into `null`, which renders the `{P}`-less form (§3.0 rule 1: no name is ever invented). Recorded
because §3.0 will read as contradicted otherwise; the sentence is what changed, not the rule.

**D2 — restored as a parameter, and the default is `false`.** A4 refuses the promise on any sentence
rendered after an attempt has finished, which is every surface that ships today. The clause exists
once in the deck and both forms are pinned, but nothing in the app passes `true` — and **no selector
was written from `LastOutcome`**, because the outcome is published only after a finished attempt and
so structurally cannot be the evidence. **The caller that renders a mid-chain status line (E7.S4 /
E7.S5) passes it from its own position in the chain.** Writing a predicate that returned `false` for
every input would have looked like the fork was implemented when it is not.

**The composition shape.** The nine rows are `public const`s assembled from `private const`
fragments. Two reasons, both hard: `UserMessagesTests` reads every public const reflectively as one
row of `Sentence(kind)` (a `static readonly` escapes five house rules at once), and the `{P}`-bearing
render is then built from *the same fragments as the const* — one string with a different subject,
not two sentences to keep in step. This is UX-DR19 applied one level down, and it is why the
occurrence scan matches fragments rather than whole sentences.

**Length.** §3's "≤ 90 characters" is now measured where it is meant to be — **rendered**. With
`{P}` = `Google` and `{t}` = `0:58` the longest row (`Blocked`) is exactly 90; the `{P}`-less
fallbacks run to 106 because "The translation service" is 23 characters against an engine name's 6.
The house rule is therefore two rules: ≤ 90 rendered, ≤ 110 for the fallback const. That is not a
weakening — A3/A5 moved the two surfaces with a hard budget of their own (the 360 px overlay, the
feed row) off these sentences entirely, and both gained their own budget assertions.

**Ruling E7-a landed here, in two halves.** `CountdownJoinText` is now the **coarse** band — null
under a minute (A12's clause takes over), `about N min` above — so no sentence that is written once
and never repainted can show a frozen `m:ss`; only the 1 Hz LIVE lines do. And the display cap reads
**`more than 30 min`** on both bands: `QuotaOpenMinutes` is 60 against a 30-minute cap, so "about"
was rounding a possible hour *down*, the one direction §2.4's "rounded up" may not break.

**Two E1.S6 review findings closed** (both were recorded as E7.S1's): a user **Stop mid-batch** no
longer paints a timeout sentence over abandoned rows — the `ct.IsCancellationRequested` check is at
the call site, as the finding said, and those rows take `(not translated — read cancelled)`; and the
**bare `OperationCanceledException`** that rendered the CLR's localised "The operation was canceled."
can no longer reach a row, because A5 means no row renders `Friendly` at all. `UserMessages.For` is
unchanged on that arm: broadening it to `OperationCanceledException` would make a genuine cancel read
as a timeout, and there is no honest sentence for a cancel (§2.1: it renders nothing).

**The per-line placeholders (ruling E2-d) collapse to one row text**, which is A5 read literally
("three row texts exist and no more"). It kills two shipped defects at once: `(skipped —
rate-limited…)` / `(rate-limited — try again shortly)` said "rate-limited" on rows that had failed
for any reason at all, and `(translation failed: {ex.Message})` could put an HTTP status code on
screen. The three *symbols* survive so the tests still say which branch produced which row; the
diagnostic text is what E1.S5's per-request log records, and it stops being what the player reads.

**One deck row was deliberately NOT written**: §3.2's overlay column for the hiccup row
(`⚠ one read is retrying`). `SetScreenStatus` writes one string to both surfaces, so it would be copy
that never renders — UX-DR19's failure the other way round. The per-surface split for the LIVE rows
is **E7.S5's**; the paused rows already have theirs only because E7.S2 needed a second writer for the
1 Hz repaint. A comment in `UserMessages.cs` says so at the point a reader would look for it.
